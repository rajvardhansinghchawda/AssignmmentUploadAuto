# Assignment Automation AI Agent

Automated assignment upload system for PIEMR student portal.

- **Backend**: Django + Celery + Gunicorn
- **Frontend**: React + Vite + Tailwind
- **AI**: Groq (llama-3.3-70b-versatile with model pool fallback)
- **DB**: Neon PostgreSQL
- **Queue**: Upstash Redis
